# Workroom Portal

팀이 만든 산출물을 **개인 → 팀 공유 → 관리자 감독**의 흐름으로 다루는
사내용 워크룸 포털. 표준 라이브러리 기반 파이썬 백엔드와 React/TypeScript
프론트엔드로 직접 만들었습니다.

  <img src="./docs/images/workroom-portal-preview.png" alt="Workroom Portal 관리자 대시보드" width="100%" />
</p>

> 사내 운영본에서 조직·구성원 정보를 제거한 **공개판**입니다. 계정·팀·경로는
> 모두 예시 값(`team-alpha` / `사용자1` 등)으로 치환돼 있습니다.

## 무엇을 푸는가

여러 사람이 각자 작업하다 결과물을 팀에 넘기고, 관리자가 전체를 점검해야
하는 상황에서 **누가 무엇을 어디까지 볼 수 있는지**가 흐트러지기 쉽습니다.
이 포털은 그 경계를 파일 시스템 위에 고정합니다.

- **개인 작업공간** — 본인만 봅니다
- **팀 공유** — 개인에서 공유로 옮긴 산출물만 팀원이 봅니다
- **관리자** — 전체를 열람하고 보관·검색·감사 흐름을 운영합니다

이동은 되돌릴 수 있고(보관함), 권한 밖 접근은 차단 기록으로 남습니다.

## 기능

| 영역 | 내용 |
|---|---|
| 파일 브라우징 | 트리 탐색, 스트리밍 다운로드, 대용량 분할 전송 |
| 미리보기 | Markdown 렌더, 코드 하이라이트, 이미지·문서 인라인 |
| 권한 경계 | 작업공간 스코프별 접근 판정, 차단 사유 기록 |
| 관리자 | 전체 산출물 검색, 보관함(복구 가능한 삭제), 사용자별 점검 |
| 에이전트 작업 | 비동기 작업 큐, 진행 상태 추적, 결과 산출물 연결 |
| 자체 점검 | 1,400줄 규모의 셀프테스트 — 권한·경로·스트림·회귀 |

## 구조

```text
portal_app.py        진입점 · 라우팅 조립
portal_router.py     URL → 뷰 디스패치
portal_auth.py       세션·권한 판정
portal_core.py       작업공간 스코프 규칙 (개인/공유/관리자)
portal_api.py        JSON API (1,860줄)
portal_file_*.py     탐색 · 상세 · 스트리밍
portal_admin_*.py    검색 · 보관함 · 공통
portal_agent_jobs.py 비동기 작업 큐
portal_selftest.py   자체 점검 스위트 (1,443줄)
frontend/            React + TypeScript + Vite (Playwright 스모크 포함)
```

백엔드는 **외부 웹 프레임워크 없이** 파이썬 표준 라이브러리로 작성했습니다 —
HTTP 처리, 라우팅, 세션, 템플릿을 직접 구현해 의존성과 배포 표면을 줄였습니다.

## 실행

```bash
python3 setup_workroom_portal.py   # 작업공간·계정 초기화 (예시 구성)
python3 portal_app.py              # 포털 기동 (기본 8787)
```

```bash
cd frontend
npm install
npm run dev
```

자체 점검:

```bash
python3 portal_selftest.py
```

## 설계에서 신경 쓴 것

- **권한은 경로에서 나온다** — 스코프 판정을 한 곳(`portal_core.py`)에 모아,
  뷰마다 권한을 다시 해석하지 않도록 했습니다
- **삭제는 복구 가능해야 한다** — 보관함을 거치고, 관리자가 되돌릴 수 있습니다
- **차단은 조용하지 않아야 한다** — 권한 밖 접근은 사유와 함께 기록됩니다
- **점검은 코드로** — 권한·경로·스트리밍 회귀를 자체 점검 스위트로 고정했습니다
